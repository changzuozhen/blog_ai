堆排序
HEAP SORT
利用堆这种数据结构来进行排序——先将数组构建为最大堆，再反复取出堆顶（最大值）放到末尾，实现原地排序，时间 O(n log n)。
时间 O(n log n) 空间 O(1) 原地 不稳定排序
核心步骤 · Core Steps
🏗️

建堆 Build Heap

从最后一个非叶节点开始，对每个节点执行向下调整（heapify），时间 O(n)

👑

取堆顶 Extract Max

堆顶即最大值，与末尾元素交换，从堆中移除

🔄

重新堆化 Heapify

对新堆顶执行 sift-down，恢复堆的性质，时间 O(log n)

🔁

重复 Repeat

重复 n-1 次取顶+堆化，完成排序
