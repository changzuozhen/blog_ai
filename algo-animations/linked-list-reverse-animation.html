链表反转
LINKED LIST REVERSE
链表反转是面试高频题——通过迭代法维护三个指针（prev/curr/next），原地将链表方向反转，时间 O(n)，空间 O(1)。
时间 O(n) 空间 O(1) 原地反转 In-place
核心思想 · Core Concept
👈

prev 指针

指向已反转部分的最后一个节点（初始为 null）

📍

curr 指针

当前待处理节点（初始为 head）

💾

保存 next

先保存 curr.next，再将 curr.next 指向 prev

🔄

推进指针

prev=curr，curr=保存的next，重复直到结束

迭代法可视化 · Iterative Visualization
原始链表：1 → 2 → 3 → 4 → 5 → NULL
prev = NULL
curr = 1
next = 2
✅ 反转完成 Reversed!
