01 背包问题
DYNAMIC PROGRAMMING · 0/1 KNAPSACK
每件物品只能选或不选，在背包容量限制内，如何使总价值最大？DP 将大问题分解为子问题，通过状态转移逐步求解最优答案。
时间 O(n·W) 空间 O(n·W) 状态转移
核心思想 · Core Concept
// 状态转移方程 State Transition
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
// 不放第i件 放第i件
// 条件：j >= w[i]
