两个栈实现队列
经典数据结构转换题
TWO STACKS IMPLEMENT QUEUE
栈是后进先出（LIFO），队列是先进先出（FIFO）。用两个栈配合，通过"倒腾"元素实现队列的 push/pop/peek 操作。
push O(1) pop 均摊O(1) 空间 O(n)
核心思想 · Core Concept
📚

栈 Stack (LIFO)

后进先出 Last In First Out

push 入栈 → 从顶部压入
pop 出栈 → 从顶部弹出

⇆
🚌

队列 Queue (FIFO)

先进先出 First In First Out

enqueue 入队 → 从尾部加入
dequeue 出队 → 从头部取出

🔑 关键：inStack 负责 push；outStack 负责 pop，outStack 为空时才从 inStack 搬运
